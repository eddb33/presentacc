03

Una herramienta para conocer a cada persona

Para centralizar el personal de estas 23 oficinas nace una herramienta que funciona bajo la órbita de la OATE y organiza áreas, referentes, oficinas y personas. Conocer el cargo, la función, el área y el referente de cada persona es la base para decidir movimientos y rotaciones.

06

La estructura que representa

El sistema está pensado para el universo de oficinas bajo la órbita de una Dirección, organizadas por áreas y referentes.

4
Centros Judiciales
23
Oficinas dependientes

Este es el nivel de oficina para el que fue concebido el sistema. Capital cuenta con desarrollo avanzado; en el Centro Judicial Sur las áreas se encuentran en definición.

07

El eje del sistema

Cada persona adquiere sentido dentro de una cadena de relaciones: dónde está, de qué área depende y quién la referencia.

Personas + oficinas + áreas + referentes + funciones + movimientos + historial + documentación = una representación dinámica de la organización.

08

Áreas y referentes

Las áreas agrupan las oficinas dependientes de la Dirección. Cada área tiene un referente, que permite comprender su relación con las oficinas y las personas que las integran.

13

Organigramas dinámicos

Al conocer las áreas, oficinas, referentes y personas, el organigrama se construye a partir de la información vigente — no de un documento estático.

Se actualiza automáticamente cuando cambian las personas o las oficinas.
